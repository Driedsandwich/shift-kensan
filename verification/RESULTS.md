## 再実行

```sh
npm ci
npm test
npm run build
npm run eval
npm run verify:ui
npx tsx scripts/verify-design.ts
npx tsx scripts/verify-polish.ts
```

PlaywrightのChromiumを使用します。既存ブラウザを使う場合は `CHROMIUM_EXECUTABLE=/path/to/chrome` を指定できます。追加検証の出力先は `POLISH_OUTPUT`、C3画面検証は `C3_OUTPUT` で指定できます。

配布フォルダの `before/` と `after/` に同条件で撮影した画像があります。比較画像の再生成は `npx tsx scripts/compare-polish.ts /path/to/delivery`。HTMLにも画像を埋め込み、ネット接続なしで見比べられます。
