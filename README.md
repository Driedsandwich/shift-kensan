# シフト検算

学生のシフト表・給与明細・メモを表に直し、働いた時間・最低賃金・割増をコードで検算する Web アプリです。

- 公開デモ：<https://x160-shift.vercel.app>（2026-11-06 時点で実 AI に接続した構成）
- 東京AIハッカソン 2026 のために作りました。
- AI の鍵（API キー）がなくても、手元では見本の応答（mock）で最後まで動きます。動かし方は下の節にあります。
- ライセンス：MIT（[LICENSE](LICENSE)）。`docs/sources/` の資料は厚生労働省などの公的資料の写しで、各提供元の利用条件に従います（MIT の対象外）。

C3 UI更新：変更点・再実行は [CHANGELOG-C3.md](CHANGELOG-C3.md)、仕様は [DESIGN.md](DESIGN.md)、最終検証は [verification/RESULTS.md](verification/RESULTS.md) を参照してください。

名前の案：**① シフト検算**（採用）／ **② はたらいた分** ／ **③ シフトのものさし**

学生のシフト表・給与明細・自由なメモを表に直し、働いた時間・最低賃金・割増をコードで検算するWebアプリです。準備、報告書、研修、片付けも記録に含められます。差額の見込みと、雇い主や相談窓口と確認する材料を示します。**法的な判断や違法性の断定はしません。**

## すぐ試す

Node.js 22.12以上を用意し、このフォルダで実行します。

```sh
npm ci
npm run dev
```

表示されたローカルURLを開きます。環境変数がなくても mock が動きます。「見本で試す」→表を確認→確認チェック→「この内容で検算する」で最後まで進めます。

| 見本 | 内容 | 初期設定での結果 |
|---|---|---|
| A | 東京、コマ給、授業外の準備15分・報告書10分が明細にない | 実働355分、下限の参考額7,787円、支払5,400円、差額2,387円 |
| B | 時給1,400円、18:00〜23:00、深夜割増なし | 実働300分、試算7,350円、支払7,000円、差額350円 |
| C | 時給1,400円、17:00〜21:00、記録どおり | 実働240分、試算・支払5,600円、差額0円 |

見本のPNGは実際に読める日本語の表で、全て架空です。**mock は見本IDで固定の転記結果を返します。画像認識に成功したと見せかけません。** 任意の自由文には決定的なルール抽出を行い、任意の写真は「mockでは読めない」と明示して手入力へ進めます。実AI接続時はその場の写真・自由文をモデルに渡します。

## AIとコードの分担

| 処理 | AI | コード・本人 |
|---|---|---|
| 写真・自由文 | 日付、区間、休憩、コマ、作業、支払額をJSONに転記 | data URLへの画像縮小、JSON型・範囲・必須キーの検査 |
| 不明な事実 | null、不明点、最大3つの質問を返す | ゼロで埋めず、本人が表を直す。質問への回答は表の編集 |
| 「前に15分」の表現 | before / 15分を抽出 | 開始時刻から15分を引く。AIに時刻の計算をさせない |
| 賃金・割増 | **計算も判定もしない** | 最低賃金の発効日、実働、週、深夜、休日、差額を検算 |
| 雇い主への言い方 | 許可した冒頭・結びの組合せを選んで文を構成 | 中央の事実は固定のスロット。計算結果を差し込み、項目名・単位・数値の全文を照合 |
| 不正なAI文 | 任意の数字、時刻、法的断定を混ぜても採用しない | 許可された形と異なれば破棄し、コードの定型文へ戻す |
| 検算後の修正 | 追加のAI呼び出しなし | 修正した事実から再計算し、相談文も再生成 |

抽出と相談文の言い回しを**同じ1回の応答**に含めます。JSONが不正な場合だけ1回取り直し、最大2回です。通信エラーは勝手に再送しません。相談文のための3回目はありません。AIの相談文は自由作文ではなく、数値の入れ替えや違法断定を防ぐ制約付きの生成です。

## 入力・編集・検算

1. 勤務地の都道府県、時給／コマ給を選び、文か写真（JPEG/PNG/WebP、3枚まで）を入れます。文と写真を一緒に送れます。
2. 読み取った表と原本を見比べます。日付・時刻・コマ数・支払額・作業の指示の有無を編集できます。
3. 休憩は開始・終了を入れます。働いている区間と重なる休憩は除き、同じ作業の重複は1回だけ数えます。未記載の空白を勝手に休憩にしません。
4. 日別支払額が不明なら月の額を入力できます。**入力した勤務と同じ期間**の、税・保険控除前の通常賃金＋割増を入れ、交通費等を除きます。月額を勝手に日割りしません。
5. 前提を確かめて検算します。根拠を開くと、時刻区間・分数・時給・率・金額が見えます。
6. 相談文のコピー、印刷、数値と根拠のJSON保存ができます。自動で雇い主や窓口に送る機能はありません。

「先週」は入力欄の基準日の前の月曜〜日曜です。曜日だけで年月日が不明なら本人に確認します。翌日1時は `25:00`、または終了 `01:00` を入力できます。開始と終了が同じなら24時間勤務とは推定せず止めます。各カードは始業が当日、全体24時間以内。同じ日の勤務は1枚のカードにまとめます。

**仮の前提として変更できるもの**：週の起算曜日、指示不明の作業を含むか、法定休日の日付、月合計の円未満、コマ給の試算基礎。1分単位の労働時間は切り捨てません。日別は端数を保持し、月別で丸めるため日別表示の和と少しずれる場合があります。通達が認める全ての端数処理を再現するものではありません。

**コマ給**：初期値は地域別最低賃金を基礎にする下限の参考額です。コマ単価×コマ数は別表示します。契約によって本来の授業外賃金や割増の基礎が高くなる可能性があるため、コマ単価÷授業時間を全作業に使う比較も選べます。出来高払の契約分類・異なる作業単価の精算は未実装です。

**最低賃金の比較**：通常分の最低額と契約上の通常額を別表示します。割増を含む支払総額だけで最低賃金を満たすと判断しません。実際の通常分と割増の内訳・対象手当は本人と雇い主が確認する必要があります。

**範囲外・未実装**：2026年4〜12月以外、変形・フレックス・裁量労働、週44時間特例、特定最低賃金、減額特例、複数勤務先の通算、固定残業代、各種手当・税・社会保険、月途中の給与締め日、代替休暇、法定休日付与の全期間判定。18歳以上の一般的な雇用を想定し、18歳未満の深夜業制限等は判定しません。期間の勤務が欠けると時間外を過小計算するため、画面で注意を表示します。

## 本番AIの設定

サーバーのproviderを環境変数で選ぶ形です。OpenAI互換の `/chat/completions` を使用します。秘密をフロントに埋め込みません。**鍵をソースやREADMEへ記入しないでください。`.env.example` は作っていません。**

| サーバー環境変数 | 用途 |
|---|---|
| `AI_PROVIDER` | 未設定／`mock` は鍵なし。`openai` はOpenAI互換接続 |
| `AI_API_KEY` | 提供元の鍵。ホスティングの秘密設定にのみ登録 |
| `AI_MODEL` | 画像入力とJSON応答を扱えるモデルの識別子 |
| `AI_BASE_URL` | HTTPSのAPIベース。省略時はOpenAIの `/v1` |
| `RATE_LIMIT_SECRET` | 本番で必須。32文字以上のランダムな署名用秘密 |
| `RATE_LIMIT_MAX` | 署名Cookieの1分あたり上限。初期8、最大30 |
| `IP_RATE_MAX` | 関数インスタンスの接続単位の10分上限。初期60 |

画像は端末で縮小・JPEGへ変換してメタデータを落とし、data URLで渡します。最大3枚、合計data URL長320万文字未満。文12,000文字、勤務62件、区間は1勤務20件まで。出力はZodで検査し、不正なら1回だけ再取得。1リクエストのAI処理は全体48秒以内、1呼出し23秒以内、クライアント53秒、Vercel関数60秒です。

## Vercelに公開する

新しいGitリポジトリとしてこのフォルダを登録し、VercelでImportします。

- Root Directory：このアプリのルート
- Build Command：`npm run build`
- Output Directory：`dist`
- Node.js：22以上（22系で検証）
- 必要なら上記のサーバー環境変数を設定し、再デプロイ

`build`が `api/analyze.js` を毎回生成します。関数は1本だけです。生成済みファイルも同梱しています。Viteの開発時も同じHTTPハンドラーを使います。`npm run preview` は静的配信のみなので、AI/APIを含む確認には `npm run dev` または公開先を使ってください。ビルド後のAPI確認は `npm run verify:ui` でも行えます。

自分で公開した場合は、公開URLをシークレットウィンドウで開き、3見本と新しい文で検算し、写真を使う本番AIで確認してください。ログイン必須のDeployment Protectionが付いていると他の人が開けないため、公開URLの閲覧設定を確認してください。

## 保存・回数制限

- 入力、画像、氏名、結果をファイル、DB、アプリのログに書きません。ブラウザのlocalStorage/sessionStorageにも保存しません。処理中のメモリだけで扱い、リロード・消去で消えます。
- 回数制限の署名Cookieと、短い時間窓のIPのHMAC・回数だけを使います。生のIPや書類は保持しません。
- Cookie削除、複数インスタンス、再起動をまたぐ完全な予算制限ではありません。強固な共有カウンターは未実装です。提供元で利用額上限も設定してください。
- 本番AIには記録が送信され、提供元のデータ保持条件が別途適用されます。AI提供元・ホスティング側の保持を、このアプリから保証することはできません。
- 写真は氏名・住所・口座等を隠してから選んでください。自動黒塗りは未実装です。
- CSP、同一Origin、本文サイズ、MIME、型、回数、タイムアウトを検査。提供元のエラー本文・鍵を返さず、入力文の命令はデータとして扱うよう指示します。

## 大きな仕組みへつなぐ意図

紙の読み取りだけでは、賃金の確認まで届きません。本アプリは個人の曖昧な記録を、本人が直せる事実と、版が明確な公的ルールと、追跡できる計算根拠に分けます。学生が雇い主・学校の相談窓口・公的機関と同じ資料を見ながら話せることを目指します。制度や業界の集計に拡張するとしても、今回の実装は個人の資料を蓄積しない構成です。
