# 評価台本

## A. 検算：合成41件

`cases.ts` は時給1,500円を中心に、人が式を書いて固定した正解です。正解を検算関数から生成しません。各ケースには入力JSONに相当する `sheet`、前提 `settings`、正解 `gold`、手計算の説明 `manual` があります。

- 通常賃金、最低賃金の発効日前後・発効日またぎ
- 22時・5時の1分境界、日8時間・週40時間の超過、重複除去
- 6時間・8時間の休憩の厳密な境界、深夜の休憩
- 休日と深夜、休日と時間外の非重複、休日の0時境界
- 週起算日の変更、日をまたぐ連続勤務
- 月60時間を超える50%と深夜25%の重なり
- コマ給の下限、準備・報告書、指示不明の含む／除く
- 支払額不明、月額支払、同月と異なる月の過不足、丸め方

採点はケース単位。分数・試算額・差額、ケースに指定された時間外・深夜・休日・休憩・必要休憩が全て一致した場合に合格です。金額の数値比較には浮動小数の誤差1e-6のみ許容します。月の円未満の処理は正解に明記しています。

## B. 抽出：自由文10件

`extraction-cases.ts` に手で決めた53項目の正解があります。採点対象は日付、開始・終了、区間種別、指示、時給、コマ単価・分数、支払額、欠損値、勤務件数。説明文や質問の文言は採点しません。相対時間はコードの正規化後で比較します。`先週` の基準日は2026-11-06で固定しています。

`matched / total` が項目一致率。全項目が合った入力の数も別に記録します。接続失敗はその入力の全項目を不一致とし、黙って評価対象から外しません。

```sh
npm run eval          # 合成計算 + mockの抽出
npm run eval:real     # 合成計算 + 本物のproviderの抽出（鍵とモデルの設定が必要）
```

mock はルール抽出器なので、100%でも本物のAIの精度を意味しません。本物の画像認識、手書き、多様な明細様式の性能はこの10文では評価できません。画像の実AI評価は未実施です。

## C. 審査員の操作台本（約3分）

1. 「授業の前後が入っていない」の見本を選ぶ。元の画像を開いて表と見比べる。
2. 準備16:45〜17:00、報告書22:30〜22:40を確認し、確認チェックを付けて検算。差額2,387円を確認。
3. 日別の根拠を開く。最低賃金1,280円、深夜40分、割増25%を確認。
4. 「表・前提を直して再検算」から支払額を7,787円に直す。差額0円、相談文も同じ数になることを確認。
5. 入力を消し、深夜の見本（差額350円）と支払の合う見本（差額0円）を試す。
6. 新しい文を入力する：`2026-11-05、18:10〜23:20勤務。時給1733円。休憩なし。支払額8954円。` → 差額578円。
7. 日付がない文、支払額不明、休憩の時刻不明を試し、勝手にゼロ・日付・時刻が補完されないことを確認。
8. 実AIの公開先で自分の写真を試す。氏名等を隠し、転記を確認してから検算する。mockの公開先では写真を読めない旨が表示される。
